## ⚠️ Observações

- Novos usuários cadastrados no sistema só poderão acessar o painel administrativo após aprovação do administrador.

- A validação de CPF não foi implementada neste projeto para evitar o uso de dados pessoais reais durante o desenvolvimento.

---

## 📋 Sobre o Projeto

O sistema foi criado com o objetivo de facilitar a administração de pet creches, permitindo o gerenciamento de:

- Cadastro de animais de estimação
- Cadastro de tutores
- Cadastro de funcionários
- Cadastro de Turma
- Cadastro de Cargos
- Serviços de banho e tosa
